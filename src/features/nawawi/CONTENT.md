# Forty Nawawi content provenance

`nawawiContent.json` is generated by `node scripts/build-nawawi.mjs`; edit the list in that script,
never the JSON.

- **Source:** HadeethEnc. Most of the 42 come from its set of Ibn Rajab's _Jami' al-'Ulum
  wal-Hikam_ (ids 66510–66540), which holds al-Nawawi's 42; #2, 8, 12, 14–16, 18, 24, 25, 31, 34–36,
  39, 40 and 42 from its general collection. Each entry keeps HadeethEnc's text, grade, attribution,
  explanation and lessons, and links back to it.
- **Check:** the script names each hadith's narrator and fails unless the hadith's own opening
  names him, so a wrong id can't slip in. Zero-width non-joiners in the source text are removed.
- **Exams:** questions are generated on the server from the Prophet's quoted words (`sayings`):
  complete the hadith, the missing word, and the narrator. Four parts (1–10, 11–20, 21–30, 31–42)
  and a final over all 42; the final's pass issues the certificate (`nawawi_certificates`,
  migration `20261013000001_nawawi.sql`).
- **Certificate quote:** the first sentence of HadeethEnc #5518, «من يرد الله به خيرًا يفقهه في الدين».

This documents provenance, not an independent review by a scholar.
