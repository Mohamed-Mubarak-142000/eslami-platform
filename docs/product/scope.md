# PROD-001 — نطاق الـMVP

## الوعد والنتيجة

الاسم التشغيلي: **بصيرة** (مؤقت حتى اعتماد العلامة). تمكّن المنصة القارئ العربي من
الوصول إلى معرفة إسلامية منسوبة بوضوح إلى صاحب مؤهل ومصادر قابلة للمراجعة، مع عرض
الخلاف المعتبر دون تحويل التفاعل إلى مسابقة شعبية.

النتيجة الأساسية: يصل المستخدم إلى إجابة موثقة ويفهم من أجاب، وفي أي تخصص، وما
المصادر، ومتى حُدثت الإجابة.

## P0 داخل النطاق

| Capability | النتيجة المطلوبة |
|---|---|
| CAP-AUTH | تسجيل/دخول/استعادة، جلسة، onboarding قابل للاستكمال، إعدادات حساب وخصوصية |
| CAP-FEED | تبويبات «لك/تتابعهم/الأحدث»، pagination، استعادة موضع القراءة |
| CAP-CONTENT | عرض منشور/مقال/إجابة، هوية المؤلف، المصادر، التحديث، helpful/save/share/report |
| CAP-SAVE | مجموعة افتراضية ومجموعات بسيطة: إنشاء، تسمية، حفظ، إزالة |
| CAP-EXPLORE | استكشاف موضوعات وعلماء وأسئلة ومحتوى حديث |
| CAP-SEARCH | اقتراحات ونتائج مبوبة وفلاتر قابلة للمشاركة وحالة صفر نتائج |
| CAP-PROFILE | ملف عالم، حالة الثقة، المؤهلات، التخصصات والمحتوى العام |
| CAP-QA | سؤال عام/خاص، نتائج مشابهة، تتبع الحالة، إجابات موثقة وآراء متعددة |
| CAP-NOTIFY | مركز إشعارات داخل التطبيق لتغير السؤال/التوثيق ووصول الإجابة |
| CAP-VERIFY | تقديم طلب توثيق ورفع أدلة وتتبع الحالة ومراجعته إداريًا |
| CAP-MOD | بلاغات، قوائم مراجعة، قرار مسبب، إيقاف/استعادة، سجل تدقيق |
| CAP-TAXONOMY | إدارة أساسية للموضوعات والتخصصات بواسطة المدير |
| CAP-STATES | حالات التحميل/الفراغ/الخطأ/عدم الاتصال/منع الصلاحية لجميع المسارات |

## P1 مؤجل صراحة

- قارئ PDF/الأبحاث وإدارة المراجع المتقدمة.
- صفحات المؤسسات وفرق العلماء.
- البريد وPush، حفظ البحث، البحث المتقدم، تحليلات العالم، تعدد اللغات.
- بحث دلالي يعيد محتوى موجودًا فقط؛ لا يولد حكمًا شرعيًا.

## خارج النطاق

- المحادثات والمجموعات والقصص والفيديو القصير والبث والمكالمات.
- الدورات والفعاليات والسوق والاشتراكات والتبرعات.
- تعليقات عامة مفتوحة أو تقييم نجوم أو ترتيب العلماء حسب الشعبية.
- إجابة أو فتوى مولدة آليًا، وشارة توثيق مدفوعة.
- تطبيقات native؛ المطلوب Web responsive عربي RTL.

## قيود الإصدار

- العربية هي اللغة الوحيدة في P0، مع RTL وmobile-first وWCAG 2.2 AA هدفًا.
- بيانات الـmock خيالية وغير منسوبة لأشخاص أو مؤسسات حقيقية.
- الصفحات العامة قابلة للفهرسة؛ الحساب والخاص والإدارة وطلبات التوثيق `noindex`.
- لا نجاح مرئي لعملية حساسة قبل تأكيد الخادم.

## بوابات Go/No-Go

1. اعتماد خبير شرعي/تحريري لنموذج الإجابة وسياسة الخلاف والمصادر.
2. اعتماد قانوني/خصوصية لسياسة السؤال الخاص ووثائق التوثيق والاحتفاظ.
3. Threat model للرفع، الوصول الإداري، التسريب عبر البحث/analytics/cache.
4. اختبار قابلية استخدام: 5–8 قراء، 3 علماء/باحثين، 2 مشرفين؛ ينجز 80% البحث
   إلى إجابة وطرح السؤال دون مساعدة.
5. اختبارات الصلاحيات والخصوصية وRTL وkeyboard/screen reader، وصفر عيوب P0/P1 مفتوحة.

## قرارات غير مانعة للتصميم ومطلوب اعتمادها قبل الإنتاج

- الاسم النهائي ونبرة العلامة.
- مدة الاحتفاظ بالأدلة والأسئلة الخاصة والأثر بعد حذف الحساب.
- الجهة المخولة بتحديد «الخلاف المعتبر» ومعاييرها التفصيلية.
- مسار الاستئناف ومدة SLA للتوثيق والإشراف.
