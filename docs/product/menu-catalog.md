# PROD-MENU-01 — منيو Twister الموحّد (محتوى مبدئي — كل الأسعار `owner-confirm`)

## تسوية التصنيفات

بريف العميل يذكر تصنيفات مختلفة قليلًا للرئيسية (بيتزا/كريب فراخ/كريب لحوم/
فراي/برجر/سوري/إضافات) وللمنيو (البيتزا/الاسترومبولي/البرجر/السوري/كريب
فراخ/كريب لحوم/كريب بطاطس/كريب مكس/الإضافات). القائمة الموحّدة أدناه تُستخدم
في الرئيسية (slider) وصفحة المنيو (tabs) بنفس الترتيب والمعرّفات — لا قائمتين
منفصلتين في الكود.

صاحب المطعم. المقاسات لبيتزا: صغير/وسط/كبير بفرق سعر عن السعر الأساسي (صغير).

## درجات الحرارة (لكل الأصناف القابلة للتبيّل)

`عادي` (افتراضي) → `حار` → `حار جدًا` — لا يغيّر السعر، اختياري لكل صنف طعام
رئيسي (ليس للإضافات أو المشروبات).

## مطلوب اعتماد صاحب المطعم قبل الإطلاق

- كل الأسعار أعلاه تقديرية بالكامل ويجب تأكيدها فعليًا صنفًا بصنف.
- صور حقيقية لكل صنف (لا توجد صور مصدر بعد).
- السعرات الحرارية اختيارية (`calories`) — غير مُدرجة حاليًا، تُضاف لاحقًا إن
  توفرت بيانات موثوقة من صاحب المطعم فقط (لا تُخترع أرقام سعرات).
