# نظام التصميم — بَصيرة

## 1. الاتجاه الإبداعي

الشخصية البصرية: **رصينة، إنسانية، معرفية، ومعاصرة**. نستعير من المخطوطات «الإيقاع والهوامش» لا الزخرفة الثقيلة، ومن المكتبات «الهدوء والترتيب»، ومن المنتجات الحديثة «الوضوح والسرعة».

الفكرة المميزة: **هامش المصدر**. المحتوى المهم يظهر بجواره خط رأسي رفيع وعلامات مرجعية، ليصبح المصدر جزءًا بصريًا من الهوية وليس قسمًا مخفيًا في النهاية.

نتجنب: الأخضر الفاقع، الذهبي اللامع، كثرة الهلال/المآذن، صور stock النمطية، والبطاقات المتداخلة بلا ضرورة.

| Token | Light | Dark | الاستخدام |

| `--color-bg` | `#F7F5EF` | `#101714` | خلفية دافئة كصفحة كتاب |
| `--color-surface` | `#FFFEFA` | `#17201C` | الأسطح والبطاقات |
| `--color-text` | `#17221D` | `#F3F0E7` | النص الأساسي |
| `--color-muted` | `#66736C` | `#AAB5AF` | النص الثانوي |
| `--color-primary` | `#145C45` | `#69C9A4` | الهوية والإجراء الأساسي |
| `--color-primary-strong` | `#0D4735` | `#91DDBF` | Hover/contrast |
| `--color-accent` | `#B7792B` | `#E4B564` | المراجع والتنبيه الهادئ |
| `--color-border` | `#DEDCD3` | `#33423B` | الحدود |

يجب توليد درجات 50–950 واختبار contrast آليًا؛ القيم أعلاه هي نقاط ارتكاز وليست بديلًا عن السلم الكامل.

## 3. الخطوط

- UI والعناوين: **IBM Plex Sans Arabic** أو **Noto Sans Arabic** كبديل مجاني.
- القراءة الطويلة والاقتباسات: **Noto Naskh Arabic**.
- الأرقام/المعرفات التقنية: الخط الأساسي مع tabular numerals.

السلم المقترح: 12، 14، 16، 18، 20، 24، 30، 38، 48. النص الافتراضي 16px وline-height بين 1.7 و1.9 للعربية. لا يقل نص مساعد مهم عن 14px.

## 4. المسافات والشكل

- شبكة 4px: `1=4`, `2=8`, `3=12`, `4=16`, `6=24`, `8=32`, `12=48`, `16=64`.
- Radius: 8 للعناصر الصغيرة، 12 للحقول، 16 للبطاقات، 24 للحوارات الكبيرة.
- ظل خفيف جدًا للأسطح العائمة فقط؛ الحدود وتباين السطح هما الأساس.
- عرض المحتوى المقروء: `720px`; عرض التطبيق: `1280–1440px`.
- الحركة: 120–220ms؛ انتقالات opacity/transform بسيطة، بلا حركة زخرفية حول المحتوى الديني.

## 5. Layout responsive

| النطاق | السلوك |
|---|---|
| `< 640` | عمود واحد، Bottom nav، Sheet للفلاتر، أزرار بعرض مناسب للمس |
| `640–1023` | عمود محتوى أوسع، Navigation مضغوط، drawers للسياق |
| `>= 1024` | Side nav + main + contextual rail حسب الصفحة |

الـbreakpoints تتبع حاجة المحتوى لا أسماء أجهزة بعينها.

## 6. طبقات المكونات

### Primitives

Button، IconButton، Input، Textarea، Select، Checkbox، Radio، Switch، Tabs، Badge، Avatar، Tooltip، Dialog، Sheet، Popover، Menu، Toast، Skeleton، Separator.

### Product patterns

- `ScholarIdentity`: الاسم، الصورة، الشارة، المؤهل/التخصص.
- `TrustMark`: حالة موثقة مع تفسير قابل للفتح؛ ليست علامة صح غامضة.
- `SourceCitation`: نوع المصدر، النص، الرابط، ورقم المرجع.
- `ContentCard`: variant للمنشور/المقال/الإجابة/البحث.
- `QuestionCard` و`AnswerPanel`.
- `OpinionGroup`: يعرض الآراء المتعددة دون ترتيب يوحي بحكم غير معتمد.
- `TopicChip` و`SpecializationBadge`.
- `SaveToCollection` و`FollowButton`.
- `VerificationStatus` و`ModerationDecision`.
- `EmptyState`, `ErrorState`, `PermissionState`.

### Templates

AppShell، FeedTemplate، SearchTemplate، ScholarProfileTemplate، ReadingTemplate، AskWizardTemplate، AdminQueueTemplate.

## 7. حالات إلزامية لكل مكوّن

Default، hover، focus-visible، active، disabled، loading، error، success، empty، selected، وlong-content. يجب اختبار الاسم العربي الطويل، نص مختلط عربي/إنجليزي، صورة مفقودة، ومصدر دون رابط.

## 8. أنماط الشاشات المهمة

### Feed

المحتوى هو البطل: رأس المؤلف صغير وواضح، عنوان/نص، شريط مصادر مميز، ثم أفعال قليلة: مفيد، استفسار، حفظ، مشاركة. لا نعرض أرقام تفاعل ضخمة تشجع الإثارة.

### صفحة الإجابة

تبدأ بالسؤال وسياقه، ثم خلاصة واضحة، هوية المجيب، نص الإجابة، المصادر، الآراء الأخرى إن وجدت، وآخر تحديث. يظهر تنبيه أن المعرفة العامة لا تستبدل استشارة متخصصة عند الحالات الشخصية الحساسة.

### ملف العالم

الهوية والتخصص والمؤسسة قبل أعداد المتابعين. «بطاقة الثقة» تشرح العناصر التي تحققت، ثم Tabs: إجابات، مقالات، أبحاث، منشورات.

### البحث

Search bar قوي، Tabs مع counts، filters قابلة للمشاركة في URL، highlight هادئ، ونتائج مجمعة حسب النوع. Zero state يقترح تصحيحًا وموضوعات قريبة وإمكانية طرح سؤال.

### Admin

أعلى كثافة معلومات، لون محايد، سبب القرار مطلوب، سجل زمني، وتحذير قبل القرارات الحساسة. لا نعتمد على اللون وحده لإظهار الحالة.

## 9. نبرة النصوص

- عربية فصحى سهلة وقصيرة، بلا لهجة آمرة أو أحكام قطعية غير منسوبة.
- «إجابة من عالم موثق» بدل «الإجابة الصحيحة».
- «مسألة فيها آراء معتبرة» بدل «جدل».
- «طلبك قيد المراجعة» مع زمن متوقع وخطوة تالية.
- رسائل الخطأ تشرح ما حدث وما يستطيع المستخدم فعله.

## 10. أيقونات وصور

- أيقونات خطية 20/24px وبسمك موحد؛ `currentColor`، واتجاه الأسهم يراعي RTL.
- صور العلماء بنسبة 1:1 وخلفيات هادئة؛ fallback بالأحرف الأولى.
- أغلفة الأبحاث والمقالات تولد من نظام هندسي بسيط قائم على الموضوع واللون، لا صور دينية زخرفية عشوائية.

## 11. التسليم والتوثيق

- Tokens في CSS وملف TypeScript واحد كمصدر حقيقة.
- Storybook لكل primitive وpattern مع RTL/LTR وLight/Dark وViewport variants.
- Naming دلالي (`primary`, `surface`, `danger`) لا أسماء ألوان (`green-500`) داخل features.
- Figma variables تطابق أسماء tokens في الكود.
- أي component جديد يحتاج API صغيرة، حالات موثقة، واختبارات وصول أساسية.
