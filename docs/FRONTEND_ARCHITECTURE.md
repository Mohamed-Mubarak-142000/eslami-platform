# معمارية الـFrontend — تم النقل

معمارية منصة "بَصيرة"/"المنارة" الإسلامية القديمة (BFF متعدد الخدمات، MSW،
TanStack Query) تم أرشفتها ضمن تاريخ Git (انظر tag `almanara-final`) ولا تنطبق
على "Twister Crepes & Pizza"، الذي لا يملك backend حقيقيًا في هذا المعلم
(`twister-storefront-v1`): البيانات مصدرها seed data ثابتة في `src/mocks/`
وrepositories محلية في `src/lib/repositories` (localStorage)، بلا خادم.

المرجع الحالي لقرارات البنية: [docs/product/scope.md](product/scope.md) و
[docs/product/twister-storefront-v1.md](product/twister-storefront-v1.md).
