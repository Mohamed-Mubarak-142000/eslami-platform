# خطة المنتج والـMVP

## 1. الرؤية والتموضع

**الرؤية:** أن تصبح المنصة المرجع الرقمي العربي الأسهل للوصول إلى معرفة إسلامية موثقة، مع إظهار صاحب الرأي ومؤهلاته ومصادره وسياقه.

**الوعد الأساسي:** لا نقدم «إجابة مجهولة»، بل معرفة مرتبطة بعالم موثق، وتخصص واضح، ومصادر قابلة للمراجعة.

**مبادئ المنتج:**

- الثقة قبل الانتشار.
- جودة المعرفة قبل معدل التفاعل.
- عرض الخلاف المعتبر بدل إخفائه.
- الفصل الواضح بين الرأي الشخصي والإجابة الشرعية الموثقة.
- لا شارة توثيق مدفوعة، ولا AI يفتي باسم نفسه.
- العربية وRTL وتجربة الهاتف ليست إضافات؛ هي أساس المنتج.

## 2. المستخدمون والصلاحيات

| الدور | أهم الصلاحيات في الـMVP |
|---|---|
| زائر | التصفح والبحث وقراءة الملفات والمحتوى العام |
| مستخدم | المتابعة، الحفظ، السؤال، التفاعل المنضبط، إدارة الحساب |
| عالم موثق | النشر، كتابة إجابات، إدارة الملف والمصادر واستقبال الأسئلة |
| متقدم للتوثيق | استكمال الطلب ومتابعة حالته فقط؛ لا ينشر كعالم |
| مشرف | مراجعة المحتوى والبلاغات والأسئلة |
| مدير | التوثيق، الإيقاف، التصنيفات، الصلاحيات وسجل القرارات |

يجب أن تتحقق الصلاحيات في الخادم؛ إخفاء زر في الواجهة ليس حماية.

## 3. نطاق MVP

### P0 — ضروري للإطلاق

- Authentication + onboarding + اختيار اهتمامات.
- Home feed: «لك» و«تتابعهم» و«الأحدث».
- محتوى: منشور، مقال، وإجابة؛ مع مصادر وإسناد واضح.
- Scholar profile ووسوم الثقة (الهوية، المؤهل، المؤسسة).
- Follow، Save، Collections بسيطة.
- Explore وSearch بنتائج مصنفة وفلاتر أساسية.
- سؤال عام/خاص، تصنيف، اختيار متخصص، وحالة السؤال.
- صفحة السؤال والإجابات، مع أكثر من رأي في المسائل الخلافية.
- Notifications داخل التطبيق.
- نموذج طلب التوثيق وتتبع الحالة.
- لوحة Admin أساسية للتوثيق والمراجعة والبلاغات.
- حالات loading/empty/error/offline وواجهات الصلاحيات.

### P1 — بعد إثبات الاستخدام

- Research/PDF وتجربة قراءة متقدمة.
- صفحة المؤسسة وربط العلماء بها.
- إشعارات بريدية/Push.
- بحث متقدم وحفظ البحث.
- لوحة عالم وتحليلات أساسية.
- تعدد اللغات، مع العربية كلغة أولى.

### خارج أول مرحلتين

- Chat، Groups، Stories، Reels، Live، Video calls.
- Marketplace، Courses، Events، Premium، Donations.
- توصيات أو إجابات مولّدة بالذكاء الاصطناعي.

## 6. أهم رحلات المستخدم

### قارئ جديد

زيارة ← استكشاف قيمة المنصة ← تسجيل ← اختيار اهتمامات ← متابعة علماء ← Feed مخصص ← بحث/قراءة ← حفظ أو سؤال ← وصول إجابة ← عودة.

### عالم

تسجيل ← طلب توثيق ← رفع المستندات ← مراجعة ← قبول/طلب استكمال ← بناء الملف ← نشر محتوى ← استقبال سؤال مناسب للتخصص ← إجابة بمصادر.

### سؤال

كتابة السؤال ← اقتراح نتائج مشابهة أولًا ← تفاصيل وسياق ← تصنيف وتخصص ← عام/خاص ← مراجعة قبل الإرسال ← Moderation ← توجيه لمتخصصين ← إجابة موثقة ← إشعار ← حفظ/مشاركة.

### مراجعة توثيق

قائمة الطلبات ← فحص البيانات والمستندات ← مطابقة روابط المؤسسة ← قبول/رفض/طلب استكمال مع سبب ← سجل تدقيق لا يمكن تعديله.

## 7. نموذج المحتوى في الواجهة

كل وحدة معرفة تعرض عند الحاجة:

- النوع: مقال/إجابة/منشور/بحث.
- العنوان والملخص والمحتوى.
- المؤلف، صفته، تخصصه، وحالة التوثيق.
- الموضوعات والكلمات المفتاحية.
- المصادر ككيانات منظمة وليست نصًا حرًا فقط.
- تاريخ النشر وآخر تحديث.
- حالة المراجعة وسياسة التعليقات.
- إن كانت مسألة خلافية: الآراء، أصحابها، منهج/مذهب عند الصلة، وأدلة كل رأي.

## 8. قواعد عمل حرجة

- المستخدم العادي لا ينشر محتوى من نوع «إجابة شرعية» أو «فتوى».
- شارة العالم لا تظهر إلا بعد اعتماد إداري، مع إمكانية التعليق أو السحب.
- كل إجابة مرتبطة بكاتب موثق، وتخصص، وتاريخ تحديث، ومصادر.
- السؤال الخاص لا يظهر في البحث أو صفحات النشاط العامة.
- المحتوى المبلغ عنه يدخل Queue ولا يحذف آليًا إلا وفق سياسة محددة.
- جميع إجراءات الإدارة الحساسة تسجل في Audit log.
- لا نستخدم تقييم النجوم للعلماء؛ نعرض مؤشرات موثقة قابلة للتفسير.

## 9. قياس النجاح

**North Star:** عدد الجلسات الشهرية التي وصل فيها المستخدم إلى إجابة موثقة وقيّمها بأنها أفادته.

مؤشرات مساندة:

- Search success rate وZero-result rate.
- نسبة الأسئلة المجابة ومتوسط زمن أول إجابة.
- حفظ المحتوى ومتابعة الموضوع/العالم.
- عودة المستخدم بعد تلقي إجابة.
- اكتمال طلبات التوثيق وزمن المراجعة.
- نسبة البلاغات الصحيحة ومعدل إلغاء قرارات الإشراف.
- Core Web Vitals، معدل الأخطاء، ونجاح إتمام المسارات.

## 10. مخاطر وضوابط

| الخطر | الضابط المنتجّي |
|---|---|
| انتحال صفة عالم | توثيق متعدد الأدلة + مراجعة + سجل + بلاغ انتحال سريع |
| فتوى مزيفة | أنواع محتوى وصلاحيات صارمة + إسناد دائم |
| مشاحنات مذهبية | عرض منظم للخلاف + إرشادات + أدوات غلق النقاش والمراجعة |
| تسريب سؤال خاص أو وثائق | تصنيف بيانات، وصول محدود، إخفاء البيانات الحساسة، وسياسة احتفاظ |
| خلط AI بالعالم | وسم أي مساعدة آلية، وعدم توليد حكم شرعي مستقل |
| Feed مثير للجدل | ترتيب: الصلة + السلطة العلمية + الجودة + الاهتمام + الحداثة |

## 11. بوابات الإطلاق

- مراجعة شرعية/تحريرية لنموذج المحتوى وسياسة الخلاف.
- Threat modeling وPrivacy review، خصوصًا الأسئلة الخاصة ووثائق التوثيق.
- اختبار استخدام مع 5–8 مستخدمين و3 علماء و2 مشرفين على الأقل.
- Accessibility audit، RTL audit، واختبار أحجام خطوط عربية.
- لا شاشة بلا loading/empty/error/permission state.
- Analytics events موثقة قبل الإطلاق التجريبي.
