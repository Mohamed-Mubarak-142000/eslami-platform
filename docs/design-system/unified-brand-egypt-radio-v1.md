# Basira unified color identity

The global semantic palette now derives from the landing identity:

- Primary: Basira deep green for actions, active navigation, links, and trust cues.
- Accent: restrained gold for citations, premium details, and secondary emphasis.
- Canvas: warm ivory in light mode and near-black green in dark mode.
- Surfaces: warm white / layered evergreen with green-gray borders.

Status colors keep their semantic meanings. Focus uses green on light surfaces and gold on dark
surfaces for high visibility. Feature code must consume semantic tokens except for artwork-
specific decorative compositions.
