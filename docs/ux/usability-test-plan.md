# UX-005 — خطة اختبار قابلية الاستخدام

## الهدف والعينة

نختبر الفهم والثقة والخصوصية وإتمام المسارات قبل التطوير البصري النهائي. العينة: 5–8
قراء (`PER-01/02`)، 3 علماء/باحثين (`PER-03/04`)، و2 مشرفين/مديري ثقة
(`PER-05/06`). تشمل مستخدم لوحة مفاتيح ومستخدم قارئ شاشة إن أمكن، وهواتف صغيرة
وحاسوبًا مكتبيًا. لا تستخدم بيانات دينية شخصية أو وثائق حقيقية.

## إعداد الجلسة

- نموذج تفاعلي عربي RTL ببيانات خيالية، نسختان mobile 360px وdesktop 1280px.
- مدة 45–60 دقيقة؛ موافقة تسجيل منفصلة؛ لا نسجل بيانات حساسة أو نص سؤال حقيقي.
- الميسر يطلب التفكير بصوت عالٍ ولا يشرح معنى الشارة أو الخصوصية قبل المهمة.
- يسجل observer: النجاح، الوقت، الأخطاء، طلب المساعدة، موضع التردد، واقتباس منقح.

## أسئلة فهم بعد المهمة

1. ماذا تعني شارة «موثّق»؟ وما الذي لا تعنيه؟
2. من يستطيع رؤية السؤال في اختيارك؟ وهل يمكن أن يظهر في البحث؟
3. هل «أفادني» يعني أن الإجابة صحيحة أو أن العالم أعلى ترتيبًا؟
4. في صفحة الآراء، هل اختارت المنصة رأيًا فائزًا؟ لماذا؟
5. بعد رسالة التعارض/الانقطاع، هل نُفذ الإجراء؟ ماذا ستفعل؟

## المقاييس وبوابة القبول

- نجاح أول محاولة دون مساعدة: ≥80% لـUT-01 وUT-02 وUT-03، و≥80% إجمالًا لكل فئة.
- فهم جمهور السؤال الخاص: 100%؛ أي توقع لفهرسة/مشاركة = عيب P0.
- فهم الشارة: ≥90% يذكر التحقق ولا يفسرها عصمة/تصديق كل رأي.
- فقد مسودة أو نجاح كاذب أو كشف مورد خاص = عيب P0 يمنع التسليم.
- SUS اختياري بعد الجلسة؛ لا يعوض فشل المهام. نسجل median time لا targets مصطنعة.
- accessibility: إنجاز كل مهمة بلوحة المفاتيح، focus مرئي، والإعلانات مفهومة دون لون.
