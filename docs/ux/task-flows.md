# UX-002 — رحلات المهام

## ترميز العقد

كل رحلة تحدد البداية، القرار، النهاية، والاسترداد. `→` انتقال، `{}` قرار، `[]` شاشة/حالة.

## FLW-01 التسجيل والتهيئة — US-AUTH-01..02

`SCR-001 → SCR-003 → {نتيجة الخادم} → SCR-005 بيانات → موضوعات ≥1 → علماء اختياري
→ مراجعة → SCR-010/لك`.

- 422: `STA-FRM-01` عند الحقل مع إبقاء غير الحساس. اعتماد خاطئ: `STA-AUT-01` بلا كشف
  وجود البريد. offline: `STA-OFF-02` ومسودة محلية غير حساسة.
- العودة تستأنف آخر خطوة مؤكدة. غياب اقتراح علماء = `STA-EMP-04` مع «تخطي والمتابعة».
- session انتهت أثناء submit: `STA-AUT-02 → SCR-002 → العودة للخطوة → إعادة الإرسال يدويًا`.

## FLW-02 البحث إلى إجابة — US-SEARCH-01، US-CONTENT-01

`أي سطح عام → SCR-012 اقتراحات → إرسال → تبويبات النتائج → SCR-016/SCR-015
→ هوية المجيب → مصدر`.

- query فارغ: recent محلي + مسح. الخاص لا يدخل recent. zero: `STA-EMP-02 → إزالة فلتر |
  تصحيح | SCR-020` ولا إرسال تلقائي.
- فتح/عودة يستعيد query والفلاتر والموضع. المصدر بلا رابط يعرض بيانات المرجع كاملة.

## FLW-03 سؤال عام — US-QA-01..03

`SCR-020 عنوان → نتائج مشابهة → {فتح نتيجة؟ يعود والمسودة محفوظة} → تفاصيل → موضوع
→ تخصص → عام → إظهار الاسم؟ → SCR-021 preview الجمهور → موافقة → submit واحد
→ SCR-023 pending_moderation → routed → answered → SCR-025 → SCR-016`.

- preview يقول إن النص والإجابات قد يفهرسان، ويعرض شكل نسبة الاسم قبل الموافقة.
- 422 يعود للخطوة المعنية؛ moderation/network failure يبقي المسودة. double submit يعطل الزر
  ويحمل operation id. نتيجة غير محسومة = `STA-MUT-02` لا ادعاء نجاح.

## FLW-04 سؤال خاص — US-QA-01..03

مثل `FLW-03` حتى الخصوصية، ثم `خاص → إخفاء الهوية عن العالم → SCR-021 preview محدود
→ موافقة صريحة → SCR-023`.

- preview: «سيراه أنت والمختصون المكلفون فقط. لن يظهر في البحث أو المشاركة» وتحذير عدم
  إدخال بيانات تعريفية غير لازمة.
- لا share/related/public metadata. العالم يرى الحد الأدنى في `SCR-030/031`. غير المخول يرى
  `STA-PRV-02` دون تأكيد وجود المورد. تغيير عام لاحقًا يحتاج موافقة جديدة.

## FLW-05 تصفح وحفظ ومتابعة وإبلاغ — US-FEED-01، CONTENT-02، SAVE-01، MOD-01

`SCR-010/011/014/015 → {follow|helpful|save|share|report}`.

- guest → `STA-PER-01` ثم login والعودة. toggle optimistic مع pending يمنع التكرار ويرجع عند
  الفشل. helpful يوصف «هل أفادك العرض؟» بلا حكم صحة.
- save → الافتراضية أو اختيار/إنشاء مجموعة → نجاح معلن؛ اسم 1–60 وفريد بعد trim.
- حذف مجموعة → تأكيد يذكر أن الأصل لا يحذف. المورد المحذوف داخلها → `STA-EMP-05`.
- report → `SCR-027 سبب`؛ other يفتح وصفًا → تأكيد «وصل بلاغك للمراجعة» بلا وعد بالإزالة.

## FLW-06 إجابة عالم — US-QA-04

`SCR-030 فلتر المكلف → فتح سؤال → SCR-031 مسودة → نص → مصدر منظم ≥1 → preview
→ submit → pending_review/published`.

- خارج التخصص/غير approved: `STA-PER-03`. انتهاء session يحفظ نسخة محلية آمنة ثم login.
- تعليق التوثيق أثناء التحرير: 403 → `STA-PER-04` + تصدير/نسخ المسودة محليًا، بلا نجاح.
- 409: `STA-CNF-01` يحفظ المسودة ويجلب الحالة الأحدث؛ المستخدم يراجع ثم يعيد الإجراء.

## FLW-07 طلب توثيق ومتابعته — US-VER-01..02

`SCR-028 هوية → مسار علمي → تخصص → مؤسسة/روابط → أدلة → مراجعة/consent → submit
→ SCR-029 pending → {needs_info → فتح الحقول المطلوبة → resubmit | approved | rejected}`.

- upload: نوع/حجم من الخادم، progress/cancel/retry؛ اسم الملف يظهر داخل الطلب فقط.
- النقص يمنع الإرسال ويوجه لأول موضع. double submit idempotent. pending يقفل الحقول.
- timeline للمتقدم يعرض سببًا مهنيًا وخطوة تالية، ولا يعرض ملاحظات داخلية.

## FLW-08 قرار توثيق إداري — US-VER-02

`SCR-042 فلترة/إسناد → SCR-043 بيانات وأدلة مقيدة → {approve|reject|needs_info}
→ سبب إجباري → تأكيد النطاق → pending → إعادة session/state → audit`.

- 409 → `STA-CNF-02`: لا overwrite؛ تعرض الحالة الأحدث وتحفظ مسودة السبب محليًا.
- approve لا يظهر قبل تأكيد الخادم؛ الوصول للأدلة على أساس التكليف فقط.

## FLW-09 قرار إشراف — US-MOD-02

`SCR-040 أولوية/نوع/حالة → إسناد → SCR-041 سياق ضروري/timeline
→ {no_action|label|limit_visibility|remove|suspend|restore} → سبب → تأكيد النطاق
→ pending → audit`.

- remove/suspend يذكران الموارد المتأثرة. 409 يحفظ السبب ويجلب النسخة الأحدث.
- لا تعرض هوية المبلغ أو هوية السائل إلا بتكليف وضرورة موثقة.

## FLW-10 الإشعارات — US-NOTIF-01

`زر الرأس → SCR-025 unread/read → فتح → {مورد متاح: يفتح | غير متاح: STA-EMP-06}`.

mark one/all optimistic ويرجع عند الفشل. لا preview لنص خاص أو وثيقة.

## FLW-11 إدارة التصنيف — US-TAX-01

`SCR-044 نوع → إنشاء/تعديل → تحقق فريد → {مستخدم؟ بديل أو منع} → تأكيد → audit`.

moderator read-only مع `STA-PER-05`. 409 يعرض أحدث نسخة قبل إعادة المحاولة.
