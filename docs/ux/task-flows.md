# UX-002 — الرحلات الحرجة

## FLW-01 التصفح → الطلب عبر واتساب (الرحلة الأساسية)

```text
SCR-001 الرئيسية
  → (نقر تصنيف/CTA اطلب الآن) SCR-002 المنيو
  → (نقر بطاقة منتج) Quick Preview [نافذة] أو SCR-003 تفاصيل منتج
  → اختيار مقاس/إضافات/حرارة/كمية → "أضف للسلة" (أنيميشن تأكيد قصير)
  → (فتح CartDrawer تلقائيًا أو بنقر أيقونة السلة)
  → (اختياري) إدخال كوبون → تحقق فوري (صالح/سبب الرفض)
  → (اختياري) هدية البطاطس تُضاف تلقائيًا إن تحقق الشرط (لا تفاعل من المستخدم)
  → "إتمام الطلب" → SCR-005 إتمام الطلب
      → اختيار منطقة (تُحدّث رسوم التوصيل والحد الأدنى فورًا)
      → إن subtotal < الحد الأدنى: رسالة الفرق المطلوب، الزر معطل
      → تعبئة الاسم/الهاتف/العنوان/(علامة مميزة اختياري)/طريقة الدفع/(ملاحظات)
      → "إرسال الطلب عبر واتساب" (معالج الضغط يبني الرسالة ويفتح wa.me مباشرة)
          → نجاح: SCR-006 تأكيد (رقم الطلب + رابط بديل "إعادة فتح واتساب")
          → فشل فتح النافذة (محظورة): STA-POPUP-BLOCKED برابط بديل واضح
```

نقاط قرار واسترداد:

- تعديل السلة من أي شاشة (CartDrawer متاح دومًا) لا يفقد بيانات نموذج
  الـcheckout المُعبّأة إن كان المستخدم قد بدأها (تُحفظ في حالة الصفحة/الذاكرة
  حتى مغادرة `/checkout` بالكامل).
- الرجوع من SCR-005 إلى المنيو يحفظ السلة (Zustand + `persist`).

## FLW-02 عرض → منيو مفلتر

```text
SCR-001 الرئيسية (بانر عرض) أو SCR-007 العروض
  → نقر بطاقة/بانر عرض
  → SCR-002 المنيو (مفلترة بـ linkedCategoryId إن وُجد، وإلا تعرض السلة بالخصم مطبقًا)
```

## FLW-03 دخول الأدمن → CRUD → تصدير

```text
SCR-020 تسجيل دخول الأدمن (كلمة مرور واحدة)
  → نجاح → SCR-021 لوحة القيادة (أرقام توضيحية من السجل المحلي)
  → اختيار مورد (منتجات/عروض/مناطق/كوبونات/بانرات/إعلانات)
  → SCR-022..027: قائمة → إنشاء/تعديل (نموذج) → حفظ (يعكس فورًا في نفس المتصفح على واجهة العميل)
  → "تصدير JSON" في أي وقت → تنزيل ملف كامل
  → (اختياري) "استيراد JSON" لاستعادة نسخة، أو "تصفير" للعودة لـseed الأصلي
```

استرداد: خطأ حفظ نموذج لا يفقد الحقول المُدخلة؛ رسالة خطأ عند الحقل المخالف
تحديدًا (لا رسالة عامة فقط).

## رحلات ثانوية

- **بحث المنيو**: SCR-002 → كتابة نص → نتائج فورية (تطبيع عربي) أو STA-EMPTY
  مع اقتراح تصنيف قريب.
- **نموذج التواصل**: SCR-009 → تعبئة → "إرسال عبر واتساب" (نفس آلية checkout،
  رسالة أبسط بلا سلة) — لا نموذج بريد يحتاج خادمًا.
