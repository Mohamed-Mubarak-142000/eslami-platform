## نموذج التنقل بحسب العرض

| السطح | الهاتف `<640` | اللوحي `640–1023` | سطح المكتب `≥1024` |
|---|---|---|---|
| عام/عضو | شريط سفلي: الرئيسية، استكشف، اسأل، المحفوظات، الحساب؛ البحث أعلى | شريط علوي مختصر + قائمة جانبية Sheet | side nav ثابت + main + contextual rail اختياري |
| عالم | نفس الأساسي؛ «صندوق الأسئلة» داخل الحساب مع شارة نصية | navigation drawer للدور | عنصر «مساحة العالم» في side nav |
| مشرف/مدير | header + drawer، لا bottom nav الاستهلاكي داخل الإدارة | rail إداري قابل للطي | side nav إداري ثابت + main عريض |

الإشعارات متاحة من أي سطح مصادق عبر زر في الرأس مع تسمية «لديك N إشعارات غير
مقروءة». يظهر `SCR-045` بدل أسطح الإنشاء للحساب الموقوف.

## قواعد التنقل والعودة

1. فتح نتيجة من feed/search يحفظ `tab + filters + cursor + scrollAnchor` في history؛ العودة
   تعيد الموضع دون طلب من البداية إن ظلت البيانات صالحة.
2. تبديل تبويب feed يغير query داخل الحالة المحلية ولا يفقد موضع كل تبويب.
3. فلاتر البحث فقط تستخدم URL؛ نص السؤال الخاص والمسودات لا تستخدمه مطلقًا.
4. الـwizard يعرض «الخطوة X من Y»، يسمح بالرجوع دون فقد الحقول، ولا يسمح بالقفز فوق
   خطوة غير صالحة. العودة خارج wizard تستدعي حوار `STA-DRF-01`.
5. deep link محمي: غير المصادق → `SCR-002` مع return path آمن؛ غير المخول →
   `STA-PER-02`؛ المورد الخاص المجهول → `STA-PRV-02`.
6. تغيير الدور/التوثيق يعيد session قبل توجيه النجاح. عند فقد الصلاحية يبقى المستخدم في
   سياق آمن مع الإجراء الممكن التالي.

## أولويات المعلومات

- المعرفة: العنوان → النوع → المؤلف/التخصص/حالة التوثيق → الخلاصة → النص → المصادر → التحديث.
- الشارة: «تم التحقق من الهوية والمسار العلمي» مع رابط شرح؛ لا علامة صح منفردة.
- الخلاف: تمهيد محايد → مجموعات رأي متساوية بصريًا حسب ترتيب تحريري → أدلة كل رأي؛
  بلا winner أو نسب أو فرز popularity.
- الإدارة: الحالة والإصدار → السياق الضروري → الأدلة المقيدة → سبب القرار → التأكيد → audit.

## وصول وتنقل بلوحة المفاتيح

- رابط «تجاوز إلى المحتوى» أول عنصر، وترتيب focus مطابق للـRTL والمنطق لا للموقع المرئي.
- tabs تستخدم أسهمًا، وEnter/Space للتفعيل، مع `aria-selected`؛ dialogs تحبس focus وتعيده.
- العناوين هرمية وlandmarks واضحة؛ تغييرات async تعلن عبر live region دون نقل focus.
- الحد الأدنى للمس 44×44px، ولا إجراء يعتمد على hover أو اللون وحده.
