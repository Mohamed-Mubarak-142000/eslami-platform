# UX-004 — الحالات والنصوص العربية

## الحالات (`STA-*`)

| ID | الوصف | يظهر في | النص المقترح |
|---|---|---|---|
| STA-LOADING | تحميل بيانات/صورة | كل الشاشات | Skeleton بدل نص "جاري التحميل" حيثما أمكن |
| STA-EMPTY-MENU | بحث/فلترة بلا نتائج | SCR-002 | «لا توجد أصناف مطابقة، جرّب تصنيفًا آخر» + روابط تصنيفات قريبة |
| STA-EMPTY-CART | سلة فارغة | SCR-004 | «سلتك فاضية لسه! يلا نبدأ الطلب» + CTA تصفح المنيو |
| STA-ERROR | خطأ غير متوقع في تحميل جزء من الصفحة | كل الشاشات | «حصل خطأ، حاول تاني» + زر إعادة المحاولة، لا رسالة تقنية خام |
| STA-OFFLINE | لا يوجد اتصال | SCR-010 وأي محاولة تفاعل شبكة | «انت أوفلاين دلوقتي، تقدر تتصفح المنيو اللي فتحته قبل كده» |
| STA-CLOSED-HOURS | خارج ساعات العمل | SCR-005 قبل الإرسال | «المطعم مقفول دلوقتي، هنرد عليك أول ما نفتح تاني الساعة {HH:MM}» — تنبيه غير حاجب |
| STA-POPUP-BLOCKED | فشل فتح نافذة واتساب | SCR-006 | «المتصفح قفل نافذة واتساب، دوس هنا لفتحها يدويًا» + رابط واضح دائم الظهور |
| STA-COUPON-INVALID | كوبون غير صالح | SCR-004/005 | حسب السبب: «الكود ده منتهي» / «الكود ده غير موجود» / «لازم الطلب يوصل {X} ج.م الأقل» |
| STA-BELOW-MINIMUM | subtotal أقل من حد المنطقة | SCR-005 | «باقي {X} ج.م علشان توصل للحد الأدنى للطلب في المنطقة دي» |
| STA-ZONE-NOT-SERVED | منطقة غير مخدومة | SCR-005 | «معتذرين، لسه مش بنوصل للمنطقة دي» + رابط اتصل بنا |
| STA-GIFT-ADDED | تحقق شرط الهدية | SCR-004 | شارة صغيرة على بند الهدية: «هدية 🎁 مجانًا» بلا نص تنبيه منبثق مقاطع |
| STA-GIFT-REMOVED | لم يعد الشرط متحققًا | SCR-004 | إزالة صامتة للبند + ملخص محدث؛ لا رسالة خطأ (سلوك متوقع لا عطل) |
| STA-PRODUCT-UNAVAILABLE | منتج معطّل من الأدمن | SCR-002/003 | شارة «غير متاح حاليًا» على البطاقة، CTA الإضافة معطّل |
| STA-ADMIN-UNAUTH | دخول admin/** بدون جلسة | SCR-020..028 | إعادة توجيه صامتة لـSCR-020، لا رسالة "ممنوع" تكشف وجود المسار |

## نصوص أساسية (`CPY-*`)

| ID | السياق | النص |
|---|---|---|
| CPY-NAV | عناصر التنقل | الرئيسية، المنيو، العروض، المناطق، تقييمات، اتصل بنا |
| CPY-CTA-ORDER | زر الطلب الأساسي | اطلب الآن |
| CPY-CTA-ADD | إضافة للسلة | أضف للسلة |
| CPY-CTA-CHECKOUT | إتمام الطلب من السلة | إتمام الطلب |
| CPY-CTA-WHATSAPP-SEND | زر إرسال checkout | إرسال الطلب عبر واتساب |
| CPY-PLACEHOLDER-BADGE | شارة بيانات توضيحية | بيانات توضيحية — لسه مش نهائية |
| CPY-REVIEW-BADGE | شارة تقييم توضيحي | تقييم توضيحي |
| CPY-DISCLOSURE-SAVE | إفصاح حفظ بيانات العميل محليًا | هنحفظ بياناتك على الجهاز ده بس لتسهيل طلبك الجاي |
| CPY-ADMIN-LOCAL-NOTICE | تنبيه لوحة التحكم | الأرقام والطلبات هنا محلية على هذا المتصفح فقط، مش قاعدة بيانات مركزية |

## قواعد

- لا نص تقني خام (رسائل خطأ JS/HTTP status) يظهر للزائر مباشرة.
- كل نص بلهجة مصرية ودودة، بلا علامات تعجب مفرطة أو ضغط بيع عدواني.
- الأرقام بصيغة غربية (١٢٣ لا تُستخدم افتراضيًا) والعملة "ج.م" بعد الرقم.
