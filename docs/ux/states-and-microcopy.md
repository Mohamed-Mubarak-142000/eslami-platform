## قواعد كتابة الأخطاء والوصول

- الرسالة = ما حدث + أثره + فعل ممكن، بلا لوم أو تفاصيل أمنية أو معرف خاص.
- لا «حدث خطأ» وحدها، ولا success قبل server confirmation في السؤال/التوثيق/الإشراف.
- toast مكمل وليس المصدر الوحيد؛ الحالة تبقى قرب المورد وتعلن بـ`role=status/alert` المناسب.
- placeholders أمثلة وليست labels. العدادات لها صيغة نصية لقارئ الشاشة.
