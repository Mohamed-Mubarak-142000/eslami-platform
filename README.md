## قرار البداية

نبدأ بتطبيق ويب Responsive ويدعم RTL بالكامل، مع بيانات Mock وعقود API واضحة. نطاق أول إصدار تجريبي:

1. الدخول والتسجيل واختيار الاهتمامات.
2. الصفحة الرئيسية والمحتوى المنظم.
3. البحث والاستكشاف.
4. ملفات العلماء وصفحات الموضوعات.
5. الأسئلة والإجابات الموثقة.
6. الحفظ والمتابعة والإشعارات.
7. رحلة توثيق العالم ولوحة المراجعة الأساسية.

خارج النطاق الآن: المحادثات، المجموعات، القصص، البث المباشر، المكالمات، الدورات، الدفع، والإعلانات.
